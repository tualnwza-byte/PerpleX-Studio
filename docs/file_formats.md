# File formats and sample data

## Needed reference material

For each anonymised example, retain the original input and every generated output in a separate folder, plus a short `README` with:

- Perple_X version and operating system;
- calculation type and expected outcome;
- database and solution-model filenames (or a statement that they cannot be shared);
- commands/prompts supplied to each executable;
- whether the run succeeds; and
- important console messages.

Suggested coverage: a P–T pseudosection, a composition-variable calculation, a WERAMI table, and a known failure.

## Licence and privacy

Do not add redistribution-restricted executables, thermodynamic databases, unpublished compositions, or confidential sample identifiers to this repository. Use documented acquisition instructions and anonymised/sample-safe fixtures instead.

## Parser policy

No file parser is considered authoritative until its format is demonstrated by at least two valid fixtures and its assumptions are recorded beside the parser tests.
